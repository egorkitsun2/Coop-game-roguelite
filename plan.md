Для команды из двух человек формат Roguelite — это идеальный выбор. Вы можете разделить обязанности по классической схеме «Программист-Логик (Engine/Data)» и «Программист-Дизайнер (Gameplay/Visual)». Это минимизирует конфликты в коде (merge conflicts) и позволит двигаться в два раза быстрее.
Ниже представлен пошаговый план дуо-разработки, разбитый по ролям и спринтам.

---

## 👥 Разделение ролей

- Разработчик А (Архитектор / Data & Backend): отвечает за математику, структуры данных, логику прокачки, сохранения, генерацию уровней и механику характеристик.
- Разработчик Б (Геймплей / UX & Visual): отвечает за управление, боёвку, поведение врагов (AI), анимации, интерфейсы (UI) и сочность картинки (Juiciness).

## 🛠️ Инструменты для совместной работы

1.  Git (GitHub / GitLab): Работайте в разных ветках (feature/movement, feature/stats), чтобы не ломать код друг другу. Сливайте всё в ветку main только после проверки.
2.  Trello / Notion / Miro: Создайте простую доску с тремя колонками: Нужно сделать (To Do), В процессе (In Progress), Готово (Done). Задачи из таблицы выше распределяйте туда.
3.  Бесплатная графика: Используйте сайт Itch.io (раздел Free Game Assets) для поиска 2D-спрайтов, чтобы не тратить время на рисование на первых этапах.
